# Ahad Ali Khan — Personal Brand & Client Acquisition Site

Premium React + Vite + TypeScript foundation for Ahad Ali Khan's personal brand and sales funnel website.

## Stack

- React 19
- Vite
- TypeScript
- Tailwind CSS v4
- Framer Motion
- React Router
- Lucide React

## Scripts

```bash
npm run dev      # local development
npm run build    # production build
npm run preview  # preview production build
```

## Phase 1 (current)

Foundation only:

- Design tokens & global styles
- Routing + page placeholders
- Navbar / Footer shells
- Reusable UI primitives
- Centralized content data files

Homepage sections and conversion pages will be built in later phases.
